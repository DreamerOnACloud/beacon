# beacon

A personal collection of short, static explanations of software-engineering and AI-engineering concepts, produced with the `/teach` skill and kept in `learning/`.

## Content

- Lessons, references, learning records, and shared assets live in `learning/` (see `learning/MISSION.md`).
- Lessons are plain static HTML, one concept per lesson, linking a shared stylesheet and quiz script in `learning/assets/`.
- No build step and no framework.

## Optional playground

A lesson may include an interactive demo wrapped in the frame from `learning/assets/playground.css` (border, label, spacing only). All demo logic, controls and reset belong to the individual demo, and the demo exercises the real thing, never a fake.

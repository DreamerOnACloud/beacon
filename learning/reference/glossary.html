Glossary

Test environments

TermMeaning
LocalYour machine, with code, mocks and data you control.
Test environmentA deployed copy of the system (real API, gateway, CDN) used to check real integration. Often called staging, QA or dev.
ParityHow closely the test environment matches production in the behaviors that matter.
MockA stand-in for a real dependency; only as true as its author's assumptions.
IntegrationTwo or more real parts talking to each other.
"Real integration"Casual shorthand for integration testing against real deployed parts instead of mocks. Precise wording: "integration testing against the test environment". It is real integration with the test environment's version of the system, not with production.
Local vs test env vs prodLocal: your assumptions, mocks you control. Test env: real deployed parts, but data, auth, caching and third-party services may differ. Prod: the real thing. To justify a claim, ask what differs from prod that could affect your feature.
Unit testFast test of one piece of logic in one process.

# Test Environments Resources

## Knowledge

- [The Twelve-Factor App, X. Dev/prod parity](https://12factor.net/dev-prod-parity)
  Canonical statement of why gaps between dev and deployed environments cause bugs (time, personnel, tools gaps). Use for: the "why parity matters" argument.
- [Google Testing Blog: Test Sizes (2010)](https://testing.googleblog.com/2010/12/test-sizes.html)
  Small/medium/large test vocabulary from Google; separates in-process tests from ones that cross machines and networks. Use for: deciding which tests belong where.
- [Google Testing Blog: Test Sizes follow-up (Mar 2011)](https://testing.googleblog.com/2011/03/)
  Notes that the names matter less than a shared vocabulary. Use for: team conversations.
- [Shipyard: Staging environments vs test environments](https://shipyard.build/blog/staging-environments-vs-test-environments/)
  Vendor blog, so read for concepts, not claims about their product. Use for: what staging is for and its limits.

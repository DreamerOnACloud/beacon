## Further reading

Three concrete instances of this same idea, at three different layers of a system:

- [`import()` — MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/import) — JavaScript's dynamic import, and the canonical rationale for it: skip the up-front cost when the code might not be needed.
- [Code Splitting — webpack](https://webpack.js.org/guides/code-splitting/) — the same idea one layer up, applied to whole bundles rather than single modules.
- [Beyond Physical Memory: Mechanisms — OSTEP, ch. 21](https://pages.cs.wisc.edu/~remzi/OSTEP/vm-beyondphys.pdf) — the OS-level version: demand paging, where a page only enters physical memory on first access.

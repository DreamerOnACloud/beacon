## Try it

A flyer is photocopied once, in advance — whoever picks one up gets the same
copy. A receipt is printed fresh, specifically for this transaction, the
moment you check out. Both panes below run the exact same underlying
mechanism as those two things. Hit "Reload" on each a few times.
